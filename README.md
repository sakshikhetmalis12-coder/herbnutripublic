# 🌿 HerbNutri - Herbal and Nutrition Awareness

> **A Complete College Educational Project Website**  
> Built with pure **HTML5, CSS3, and JavaScript (ES6)**. Designed with a clean herbal green and pure white aesthetic, fully responsive across laptops, tablets, and smartphones.

---

## 📖 Project Overview

**HerbNutri** is an educational web portal designed to promote botanical awareness and evidence-based nutrition. It bridges traditional Indian herbal wisdom (Ayurveda) with modern nutritional science to help students, families, and communities maintain optimal health through natural living.

---

## ✨ Key Features

### 1. 🍃 Core Medicinal Herbs Showcase
In-depth profiles for the four essential healing herbs plus complementary traditional plants:
* **Tulsi (Holy Basil / *Ocimum sanctum*)**: Active compounds (Eugenol, Ursolic acid), immunity boosting, adaptogenic stress relief, respiratory support, and traditional Kadha recipe.
* **Aloe Vera (*Aloe barbadensis*)**: Acemannan active polysaccharides, soothing skin hydration, acid reflux relief, and pure inner-gel preparation.
* **Turmeric (Haldi / *Curcuma longa*)**: Curcuminoid anti-inflammatory powerhouse, joint mobility, piperine (black pepper) bio-enhancer facts, and Golden Milk recipe.
* **Ginger (Adrak / *Zingiber officinale*)**: Gingerol, digestive enzyme stimulation, motion sickness relief, and zesty ginger lemon elixir.
* **Bonus Traditional Herbs**: Ashwagandha (stress & stamina), Amla (highest Vitamin C superfruit), Neem (blood purifying & oral care), and Mint/Pudina (cooling digestive).

### 2. 🔍 Interactive Search & Filter System
* Filter herbs by health goal: **Immunity Boosters**, **Digestive Health**, **Skin & Hair Care**, or **Vitality & Anti-Stress**.
* Real-time search bar to search herbs by name, chemical compound, or health benefit.

### 3. 📑 Full Herb Profile & Remedy Modal Dialog
* Clicking any herb opens an interactive modal window displaying scientific classification, plant family, key active compounds, traditional Ayurvedic uses, peer-reviewed clinical findings, and safe home remedies.

### 4. 🥗 The Healthy Eating Plate & Nutrition Education
* Visual breakdown of the internationally recognized **Plate Method**:
  * **50%**: Colorful Vegetables and Fresh Fruits
  * **25%**: High-fiber Whole Grains (Millets, Brown Rice, Oats)
  * **25%**: Healthy Clean Proteins (Lentils, Dal, Paneer, Tofu, Eggs)
* Detailed guides on Macronutrients (Carbohydrates, Proteins, Fats, Dietary Fiber) and Micronutrients (Vitamins C, D3, B12, Iron, Calcium, Zinc).

### 5. ⚖️ Interactive Health Calculators
* **Body Mass Index (BMI) Calculator**: Calculates BMI score, visual status badge (Underweight, Normal, Overweight, Obese), and provides customized herbal and dietary guidance.
* **Daily Water Hydration Calculator**: Calculates daily water target in liters and glasses based on body weight and physical activity levels.

### 6. 💡 Healthy Food Tips & "Do's and Don'ts"
* Practical tips on morning hydration, the 32-chew mindful eating rule, the circadian 3-hour dinner gap, and gut microbiome health.
* Interactive **"Tip of the Day" Generator** that cycles through evidence-backed wellness insights.
* Visual **Do's vs. Don'ts Comparison Guide** for everyday choices.

### 7. 🎓 Interactive Herbal & Nutrition IQ Quiz
* 4-question interactive knowledge check with real-time feedback, correct answer explanations, score calculation, and performance badge.

### 8. ❓ FAQ Accordion & Contact Form
* Smooth interactive accordion addressing common queries (e.g. Turmeric absorption, Aloe latex safety, Tulsi dosage).
* Client-side validated contact/feedback form with toast notifications.

## 🚀 How to Run the Website in Your Browser

You can run this website on any Windows, Mac, or Linux computer using any modern web browser (**Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Safari, or Opera**).

### Method 1: The Quickest Way (Direct File Double-Click)
1. Open File Explorer and navigate to the project folder:
   ```
   c:\Users\Shree\Desktop\Herbal and Nutrition
   ```
2. Find the file named `index.html`.
3. **Double-click** `index.html` (or right-click `index.html` → **Open with** → **Google Chrome** / **Microsoft Edge**).
4. The website will immediately load and function 100% with all interactive features, images, and tools!

### Method 2: Using Windows Command Prompt / PowerShell
1. Open PowerShell or Command Prompt in the project folder.
2. Run the following command:
   ```powershell
   Start-Process "index.html"
   ```
   *(Or simply type `start index.html` in CMD)*.
3. Your default browser will instantly launch the project.

### Method 3: Using Python Built-in Local Web Server (Optional)
If you prefer running through a local web server:
1. Open PowerShell in the project folder.
2. Run:
   ```powershell
   python -m http.server 8000
   ```
3. Open your browser and visit:
   ```
   http://localhost:8000
   ```

### Method 4: Using VS Code Live Server Extension (Optional)
1. Open the project folder in Visual Studio Code.
2. Right-click `index.html` and click **"Open with Live Server"**.

## 📱 Mobile & Responsive Testing

The website is fully responsive. To test different screen sizes:
1. Open the website in your browser.
2. Press `F12` (or Right-click → **Inspect**).
3. Click the **Toggle Device Toolbar** icon (or press `Ctrl + Shift + M`).
4. Test on **iPhone 12/14/15, Samsung Galaxy, iPad, and Laptop** dimensions to verify the hamburger navigation, grids, and touch-friendly controls.

When presenting this project to your college evaluators:
1. **Highlight the Theme**: Explain the fresh green and pure white color psychology chosen specifically for herbal wellness and clean nutrition.
2. **Demonstrate the Core Four**: Show the four featured herbs required by your syllabus (**Tulsi, Aloe Vera, Turmeric, and Ginger**), click **"View Full Profile & Remedies"** to demonstrate the modal popup with traditional uses and home recipes.
3. **Live Demonstration of Tools**:
   * Calculate a sample **BMI** (e.g. 68 kg, 172 cm = 23.0 Normal).
   * Calculate sample **Daily Water Requirement** for different activity levels.
4. **Interactive Quiz**: Take the 4-question quiz live in front of the evaluator to show instant feedback and scoring logic.
5. **Clean Architecture**: Point out that the code uses pure semantic HTML5, clean CSS3 variables, and modular vanilla JavaScript without heavy external libraries, making it ultra-fast and lightweight.
